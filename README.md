# Copyshop

Graphic tools by iney.corp · https://www.instagram.com/linainey/

Open now: **Relief**. Coming soon: Bezier, Press, X-Ray, Pixel Sort.

## What is in the folder

- `index.html` — the whole site: home page and the tools.
- `img/` — pictures for the home page.

## Publish on GitHub Pages

1. Sign in at https://github.com.
2. Click **+** (top right) → **New repository**. Name: `copyshop`. Visibility: **Public**. Click **Create repository**.
3. On the new repository page click **uploading an existing file**.
4. Drag in `index.html`, `README.md` and the whole `img` folder. Click **Commit changes**.
5. Open **Settings** → **Pages** in the left menu.
6. Under **Build and deployment** choose Source **Deploy from a branch**, Branch **main**, folder **/ (root)**, then **Save**.
7. In 1–2 minutes the site is live at `https://YOUR-LOGIN.github.io/copyshop/`.

Direct link to the tool: add `#relief` to the address.

## Update the site

Repository → **Add file** → **Upload files** → drag the new files → **Commit changes**.
